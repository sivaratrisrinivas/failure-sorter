failure sorter

A small agent tried to find people in a profile index. When it missed, was it because it never saw the right person, or because it saw them and fumbled? Each miss goes in one of two bins. Click any row to read the full trace.

- retrieval miss

The right profile never came back from any tool. Fix search.

- tool misuse

The right profile came back, and the agent did not use it. Fix the harness or the model.

yellow = the right profile inside a tool result

All profiles are invented. No real person is in this index. Source: github.com/sivaratrisrinivas/failure-sorter
